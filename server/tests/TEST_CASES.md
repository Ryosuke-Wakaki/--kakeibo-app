# API テストケース仕様書

## 1. Transaction API テストケース

### POST /api/v1/transactions/

| No | テストケース名 | 分類 | リクエストボディ | 期待するステータスコード | 期待する結果 | 備考 |
|----|---------------|------|-----------------|----------------------|------------|------|
| 1 | 収入の正常登録 | 正常系 | `{"date": "2025-11-03", "transaction_type": "01", "category_id": 3, "amount": 300000, "payment_method_id": null, "description": "給与"}` | 200 | トランザクションが作成され、IDが採番される | - |
| 2 | 支出の正常登録 | 正常系 | `{"date": "2025-11-03", "transaction_type": "02", "category_id": 1, "amount": 1500, "payment_method_id": 1, "description": "ランチ"}` | 200 | トランザクションが作成される | - |
| 3 | 必須項目不足 | 異常系 | `{"date": "2025-11-03", "transaction_type": "01"}` | 422 | バリデーションエラー | category_id, amountが必須 |
| 4 | 不正な取引種別 | 異常系 | `{"date": "2025-11-03", "transaction_type": "99", "category_id": 1, "amount": 1000}` | 422 | バリデーションエラー | transaction_typeは'01'か'02' |
| 5 | 存在しないカテゴリID | 異常系 | `{"date": "2025-11-03", "transaction_type": "02", "category_id": 9999, "amount": 1000}` | 500 | 外部キー制約エラー | - |
| 6 | 負の金額 | 異常系 | `{"date": "2025-11-03", "transaction_type": "02", "category_id": 1, "amount": -1000}` | 422 | バリデーションエラー | 金額は0以上 |
| 7 | 不正な日付フォーマット | 異常系 | `{"date": "2025/11/03", "transaction_type": "02", "category_id": 1, "amount": 1000}` | 422 | バリデーションエラー | 日付はYYYY-MM-DD形式 |

### GET /api/v1/transactions/

| No | テストケース名 | 分類 | クエリパラメータ | 期待するステータスコード | 期待する結果 | 備考 |
|----|---------------|------|----------------|----------------------|------------|------|
| 1 | 全件取得 | 正常系 | なし | 200 | すべてのトランザクションが取得できる | デフォルトlimit=100 |
| 2 | ページネーション(skip) | 正常系 | `skip=2&limit=5` | 200 | 3件目から5件取得 | - |
| 3 | 空のデータベース | 正常系 | なし | 200 | 空の配列が返る | - |

### GET /api/v1/transactions/month

| No | テストケース名 | 分類 | クエリパラメータ | 期待するステータスコード | 期待する結果 | 備考 |
|----|---------------|------|----------------|----------------------|------------|------|
| 1 | 月別取得(正常) | 正常系 | `month=2025/11` | 200 | 2025年11月のトランザクションのみ取得 | - |
| 2 | データが存在しない月 | 正常系 | `month=2025/12` | 200 | 空の配列が返る | - |
| 3 | 不正なフォーマット(スラッシュなし) | 異常系 | `month=202511` | 422 | フォーマットエラー | YYYY/MM形式を要求 |
| 4 | 不正なフォーマット(ハイフン) | 異常系 | `month=2025-11` | 422 | フォーマットエラー | YYYY/MM形式を要求 |
| 5 | 月パラメータなし | 異常系 | なし | 422 | パラメータ必須エラー | - |
| 6 | 不正な月(13月) | 異常系 | `month=2025/13` | 422 | バリデーションエラー | 月は1-12 |

### GET /api/v1/transactions/{transaction_id}

| No | テストケース名 | 分類 | パスパラメータ | 期待するステータスコード | 期待する結果 | 備考 |
|----|---------------|------|--------------|----------------------|------------|------|
| 1 | ID指定取得(存在する) | 正常系 | `transaction_id=1` | 200 | 指定IDのトランザクションが取得できる | - |
| 2 | ID指定取得(存在しない) | 異常系 | `transaction_id=9999` | 404 | Not Found | - |
| 3 | 不正なID(文字列) | 異常系 | `transaction_id=abc` | 422 | バリデーションエラー | IDは整数 |

### PUT /api/v1/transactions/{transaction_id}

| No | テストケース名 | 分類 | パスパラメータ + リクエストボディ | 期待するステータスコード | 期待する結果 | 備考 |
|----|---------------|------|------------------------------|----------------------|------------|------|
| 1 | 正常更新 | 正常系 | `id=1`, `{"date": "2025-11-04", "transaction_type": "02", "category_id": 1, "amount": 2000}` | 200 | トランザクションが更新される | - |
| 2 | 存在しないID | 異常系 | `id=9999`, 任意のボディ | 404 | Not Found | - |
| 3 | 不正なデータ | 異常系 | `id=1`, `{"amount": -500}` | 422 | バリデーションエラー | - |

### DELETE /api/v1/transactions/{transaction_id}

| No | テストケース名 | 分類 | パスパラメータ | 期待するステータスコード | 期待する結果 | 備考 |
|----|---------------|------|--------------|----------------------|------------|------|
| 1 | 正常削除 | 正常系 | `transaction_id=1` | 200 | トランザクションが削除される | - |
| 2 | 存在しないID | 異常系 | `transaction_id=9999` | 404 | Not Found | - |
| 3 | 削除後の再削除 | 異常系 | `transaction_id=1`(削除済み) | 404 | Not Found | - |

## テスト実行方法

```powershell
# テスト環境のセットアップ
cd server
.\venv\Scripts\Activate.ps1
pip install pytest pytest-cov httpx

# すべてのテストを実行
pytest

# 特定のテストファイルのみ実行
pytest tests/test_transaction.py

# カバレッジ付きで実行
pytest --cov=app --cov-report=html

# 詳細表示
pytest -v
```

## 注意事項

1. **テストDB**: テスト実行時は本番DBとは別のテスト用DBを使用すること
2. **テストデータ**: 各テストの前後でDBをクリーンアップすること（fixtureを使用）
3. **独立性**: 各テストは他のテストに依存しないように設計すること
